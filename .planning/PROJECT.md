# Detectors de Fumaça e a Descoberta do Núcleo Atômico

## What This Is

Um projeto educacional de slides interativos sobre Detectores de Fumaça e a Descoberta do Núcleo Atômico, com foco no íon He²⁺. O produto é uma apresentação web em React usando Spectacle.js, complementada com simulações 3D (Three.js) e 2D (Matter.js) para ensino de química voltado a estudantes.

## Core Value

Transformar conceitos complexos de estrutura atômica e detectores de fumaça em uma experiência visual e interativa que estudantes compreendam de forma clara e envolvente.
